# Frontend location
Frontend is inside the ASP.NET Core project's `wwwroot` folder so Visual Studio shows and serves it correctly.
- `wwwroot/html/` = page HTML files
- `wwwroot/css/` = all CSS files
- `wwwroot/js/` = JavaScript grouped into api, pages, auth, components and utils
- `wwwroot/assets/` = images and icons
The actual private vault files are never stored in wwwroot.
